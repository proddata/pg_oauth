# 0.2.0 prerelease

Prepared, not published. The tag, signed archives, release record and the
evidence links below are added when the release is approved; until then this
file records scope and known limitations only. Once published, the GitHub
release is immutable and later changes require a new version.

## What changed since 0.1.3

- **PAM token authentication joins the prerelease.** `pg_oauth_pam` (PostgreSQL
  15 to 19) now has the validator's prerelease status instead of
  "experimental". It is not production-ready: the
  [PAM gate](../release-readiness.md#pam-module-gate) still governs any such
  claim and inclusion in `v1.0.0`.
- **The PostgreSQL 18 and 19 release archives contain both modules.**
  `pg_oauth_pam.so` is installed beside `pg_oauth_validator.so` in the
  PostgreSQL library directory. The archive names are unchanged. For
  PostgreSQL 15, 16 and 17 the module is built from source.
- **PAM module protections.** The PAM module and the validator keep separate
  shared caches. A module built for another PostgreSQL major version refuses to
  authenticate, and on PostgreSQL 15 and 16 a copy the server did not preload
  never runs a private cache.
- **`scp` is accepted when `scope` is absent**, for providers such as Microsoft
  Entra ID and Okta. A token with both claims is denied. Covered by unit tests
  only.
- **Identity and role-name text is validated more strictly** (invisible,
  line-breaking and text-reordering characters are refused). Check the query in
  [operations](../operations.md#upgrade) before upgrading.
- Source tree layout: shared pipeline code moved to `shared/`; the repository
  was renamed `pg_oauth`. Module names, library names, GUC prefixes and package
  names are unchanged.

## Known limitations accepted for this prerelease

- Production readiness is not claimed, for either module. Approval is the
  deployment owner's maintainer review, not independent security review.
- **PAM RPM upgrade and rollback were not rehearsed.** No earlier release
  contains the PAM package, so the baseline (rebuilt v0.1.3 source) has none.
  This is the first-release exception in
  [release readiness](../release-readiness.md#pam-module-gate); the rehearsal
  runs for real at the next release.
- PostgreSQL 15 and 16 require `shared_preload_libraries` for PAM; without it
  the module denies.
- `scp` handling has no interoperability evidence for Entra ID or Okta.
- Items carried over from [0.1.3](0.1.3-prerelease.md) apply unless this file
  says otherwise: no additional durable artifact storage, SELinux-enforcing
  evidence for Fedora 44 x86-64 only, and Keycloak as the only live provider.
  The scoped Rocky OpenSSL exception (CVE-2026-35189) expires on 2026-11-22
  and must be re-reviewed or closed before approval; see
  [the recorded exception](../rpm-dependency-review.md#controlled-endpoint-exception-cve-2026-35189).

## Installation and rollback

Use only the package built for the exact PostgreSQL major and supported
platform/architecture, and retain the previous package and protected
configuration before upgrading. See [operations](../operations.md),
[PAM](../pam.md#install) and [the RPM procedure](../rpm-platforms.md#upgrade-and-rollback-rehearsal).
